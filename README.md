# Order Tracking Screen

A responsive React + TypeScript order tracking interface designed for a mobile-first shopping experience. The app shows delivery progress, order details, product information, and customer support flows across multiple shipment states.

## Features

- Order tracking status overview
- Delivery timeline and progress details
- Product summary card
- Support and issue-reporting actions
- Preview modes for different shipment scenarios
- Tailwind-based responsive styling

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Setup and Run

1. Open the project folder:
   ```bash
   cd "TASK 1/OrderTrackingScreen"
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open the local URL shown in the terminal, usually:
   ```bash
   http://localhost:5173
   ```

## Build

To create a production build:

```bash
npm run build
```

## Additional Checks

```bash
npm run lint
npm run typecheck
```

The following prompts were used to help design and build the interface:
